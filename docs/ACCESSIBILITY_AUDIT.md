# Accessibility Audit

## Present controls

Skip link, visible focus rules, reduced-motion handling, coarse-pointer target sizing, semantic shared feedback, focus-managed modal, labelled navigation, responsive sidebar and accessible status messaging.

## Unverified/open

- No complete automated axe/WCAG run across authenticated routes.
- No recorded screen-reader workflow for authentication, topics, logbooks, evaluations, notifications or AI review.
- Keyboard and focus order need verification at 320–1440px.
- Tables/charts/forms need route-by-route name, description, error association and contrast checks.

Target WCAG 2.2 AA practices, but do not claim conformance until automated and manual testing evidence is recorded.
